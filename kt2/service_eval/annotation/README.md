# Двойная разметка

Мы проверяем, одинаково ли два человека понимают таксономию. Оба читают одни и те же 20 [карточек](cards.md). В карточках есть жалоба и наблюдения по шагам, но нет внесённой поломки и готового диагноза.

## Как провести

1. Выбираем двух людей, которые не составляли эти кейсы и не видели таблицу ответов в разделе 5.1 design doc. Это могут быть участники другой команды. Каждый берёт копию [шаблона](labels_template.csv). Один сохраняет её как `labels_A.csv`, другой как `labels_B.csv`. Во время разметки они не обсуждают ответы и не открывают `dev.jsonl` или таблицу ответов.
2. Для каждого `id` участник заполняет три столбца. В `failure_type` пишет `retrieval`, `prompt`, `model`, `tool` или `none`. В `root_step` указывает шаг из [таксономии](../taxonomy.md). При `none` оставляет ячейку пустой. В `status` пишет `confirmed`, `probable` или `unresolved`. Это предварительный статус. Пока повторных запусков нет, `confirmed` означает, что данных достаточно для проверки гипотезы при условии успешного воспроизведения. Фактический статус проверим на КТ-3.
3. Когда готовы оба файла, запускаем расчёт из корня репозитория:

   ```bash
   python3 kt2/service_eval/scripts/agreement.py kt2/service_eval/annotation/labels_A.csv kt2/service_eval/annotation/labels_B.csv
   ```

   Скрипт проверит, что размечены все 20 карточек, и запишет `agreement.json`. В нём будут доля совпадений, κ Коэна по виду, шагу и статусу, а также номера карточек с разногласиями.
4. Затем вместе разбираем расхождения и записываем окончательный ответ с объяснением в `adjudication.jsonl`. Для каждого расхождения указываем `id`, итоговые `failure_type`, `root_step`, `status` и `reason`. Если разногласие связано с неясным правилом, уточняем таксономию и повышаем версию набора. Результат согласия переносим в раздел 5.1 design doc.

Это две настоящие независимые разметки. Сгенерировать второй файл из первого или из эталона поломок нельзя: такое число ничего не скажет о понятности таксономии. Пока файлов A и B нет, согласие не посчитано и этот пункт КТ-2 остаётся открытым.
